# Architecture addendum — bounded Gravity Flow content admission

The closed localization architecture remains `Shared Core + Declarative Product Manifests + Bounded Adapters`.

`CONTENT_ADMITTED_PARTIAL` is an orthogonal content state for a source-verified product whose reviewed production catalog intentionally contains only a proven surface subset. It does not replace or weaken `PACKAGE_INSPECTED_METADATA_ONLY`, and it does not authorize other product surfaces. Runtime precedence remains provider key first, then upstream/vendor fallback, then source English.
